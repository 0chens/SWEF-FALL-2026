# Prereading.

For prereading, I want you to clone these two repos to your computer, open them in cursor, and ask the cursor AI agent questions about how the backend works. Get familiar with the backend architecture, you should be able to explain what each file in the backend folder does. Try to spend at least 10 minutes understanding what does what for each repo, I know most of you will skip doing this but if you do it will genuinely make the homework much easier and less stressful.
